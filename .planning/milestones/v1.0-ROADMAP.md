# Milestone v1.0: Technical Refresh

**Status:** ✅ SHIPPED 2026-05-17
**Phases:** 1-2
**Total Plans:** 3

## Overview

Технический milestone для brownfield CLI: проект переведен на актуальный Go/tooling baseline, встроенный self-update удален в пользу Homebrew-only distribution path, а orchestration вокруг `JustStarted` стабилизирован минимальным совместимым исправлением и regression-проверкой.

## Phases

### Phase 1: Stack and Distribution Refresh

**Goal**: Обновить toolchain и ключевые зависимости до актуальных major versions, убрать встроенный self-update и сохранить совместимость конфигов и пользовательских сценариев.
**Depends on**: None
**Plans**: 2 plans

Plans:

- [x] 01-01: Обновление Go/toolchain, прямых зависимостей и минимальная YAML/IO-модернизация
- [x] 01-02: Удаление built-in updater path, сохранение tolerant read legacy config и выравнивание docs

**Details:**
- Requirements: `TOOL-01`, `TOOL-03`, `DIST-03`, `COMP-02`
- Success criteria:
  1. `go.mod`, dependency graph и build paths переведены на актуальный поддерживаемый стек.
  2. Built-in shell-based self-update path удален из поддерживаемого runtime behavior.
  3. `workspace.yaml`, `env.yaml` и `~/.elc.yaml` остаются читаемыми без обязательной миграции.
  4. Документация и runtime assumptions согласованы с Homebrew как единственным поддерживаемым каналом установки/обновления.

### Phase 2: Orchestration Stabilization and Verification

**Goal**: Исправить dependency orchestration вокруг `JustStarted`, закрепить обратную совместимость CLI и довести проект до стабильной сборки и проходящих тестов на обновленном стеке.
**Depends on**: Phase 1
**Plans**: 1 plan

Plans:

- [x] 02-01: Активация `JustStarted` guard, минимальная regression coverage и финальная verification-проверка

**Details:**
- Requirements: `TOOL-02`, `DIST-01`, `DIST-02`, `ORCH-01`, `ORCH-02`, `ORCH-03`, `COMP-01`, `COMP-03`
- Success criteria:
  1. Dependency startup использует `JustStarted` согласованно и не переобрабатывает уже запущенные зависимости в рамках одного command flow.
  2. Исправление не ломает supported `start` / `restart` scenarios на валидных acyclic graphs.
  3. Сборка и существующий automated test suite проходят на обновленном стеке.
  4. Поведение и документация продукта остаются согласованными с Homebrew-only distribution model.

## Milestone Summary

**Key Decisions:**
- Обновить стек до последних мажорных версий, а не ограничиваться минорными апдейтами.
- Полностью удалить встроенный self-update вместо совместимого stub.
- Оставить `update_command` в `~/.elc.yaml` как harmless legacy field без runtime-семантики.
- Чинить `JustStarted` минимально, без отдельной cycle detection и без изменения семантики `restart`.

**Issues Resolved:**
- Go baseline обновлен с `1.19` до `1.26`.
- Прямые runtime dependencies обновлены до актуальных линий.
- Конфигурационный слой переведен на `go.yaml.in/yaml/v3` с сохранением порядка переменных.
- Built-in updater path удален из CLI и runtime.
- Shared dependencies перестали переобрабатываться повторно в одном command flow.

**Issues Deferred:**
- Явная dependency cycle detection с user-facing diagnostic
- Более широкое CLI wiring coverage
- Более строгая YAML schema validation
- Остальные security / architecture concerns из codebase audit вне scope этого milestone

**Technical Debt Incurred:**
- Тестовое покрытие расширено только минимально необходимым regression test'ом; core/runtime по-прежнему покрыт нешироко.
- `PROJECT.md` и roadmap-архив эволюционируют вручную, потому что локальный `gsd-sdk` здесь не предоставляет ожидаемые query-workflows.
